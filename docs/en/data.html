Data

All files are UTF-8 CSV. Some values were counted for this site (VD, STCN, ISTC, KORCIS); others were transcribed from official tables (Korean Publishers Association, Statistics Bureau of Japan, National Bureau of Statistics of China, US Census Bureau, WIPO). Data produced for this site are released under CC BY 4.0. Rights in the original sources remain with them. The ISTC source data are licensed CC BY-NC 4.0, so no records are republished here, only the counts made for this site. When reusing a file, please cite its original source as well.
